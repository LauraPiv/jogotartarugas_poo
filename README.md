# Projeto Tamar - Resgate das Tartarugas

Este é um jogo interativo sobre o resgate e preservação de tartarugas marinhas, desenvolvido utilizando HTML, CSS, JavaScript (Orientação a Objetos) e a ferramenta de build Vite.

## 📥 Como baixar o projeto

### Opção 1: Via Git (Recomendado)
Se você tiver o [Git](https://git-scm.com/) instalado, pode clonar o repositório diretamente na branch `BIGOTTO` executando o seguinte comando no seu terminal:
```bash
git clone -b BIGOTTO https://github.com/LauraPiv/jogotartarugas_poo.git
```

### Opção 2: Download do ZIP
Você também pode baixar o projeto como um arquivo ZIP. Após o download, extraia a pasta em um local de sua preferência no seu computador.

## 🚀 Como inicializar o jogo

Para rodar o projeto localmente, você precisará do [Node.js](https://nodejs.org/) instalado no seu computador.

1. **Abra o terminal** e navegue até a pasta raiz do projeto (onde está localizado o arquivo `package.json`).

2. **Instale as dependências** do projeto executando o seguinte comando:
   ```bash
   npm install
   ```
   *(Isso fará o download de todas as bibliotecas necessárias para rodar o projeto, como o Vite).*

3. **Inicie o servidor de desenvolvimento** rodando:
   ```bash
   npm run dev
   ```

4. **Acesse o jogo**! Após rodar o comando anterior, o terminal exibirá um link local (geralmente `http://localhost:5173/`). Basta clicar nesse link (ou copiá-lo e colar no seu navegador) para jogar.

## 🛠️ Tecnologias Utilizadas
- **HTML5 e CSS3** para estrutura e estilização visual
- **JavaScript (ES6+)** com Programação Orientada a Objetos (POO)
- **Vite** como empacotador e servidor de desenvolvimento local
